## File Naming Convention

Each solution is stored using the following naming format:

```text
<problem-number>.<problem-title>.py
```

Examples:

```text
1248.Count_Number_of_Nice_Subarrays.py
1525.Number_of_Good_Ways_to_Split_a_String.py
```

Spaces in problem titles are replaced with underscores.

## Code Format

Every solution generally follows this documentation format:

```python
"""
LeetCode: <problem-number> - <problem-title>
Link: <problem-link>
Difficulty: <Easy/Medium/Hard>
Time: <time-complexity>
Space: <space-complexity>
"""
```

Example:

```python
"""
LeetCode: 1525 - Number of Good Ways to Split a String
Link: https://leetcode.com/problems/number-of-good-ways-to-split-a-string/
Difficulty: Medium
Time: O(n), where n is the size of the input string
Space: O(1), additional space excluding output
"""
```
